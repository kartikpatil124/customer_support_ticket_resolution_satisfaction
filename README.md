# Customer Support Ticket Resolution & Satisfaction Analysis

## 📌 Project Overview

This project analyzes customer support tickets to understand **ticket resolution performance, response time, customer satisfaction, reopening rates, and support-channel performance**.

The project uses **Excel, SQL (MySQL), and Python** to clean, analyze, and extract business insights from customer support data.

## 📊 Dataset

The dataset contains **2,800 customer support tickets** with 10 columns:

* `ticket_id`
* `created_date`
* `issue_category`
* `priority`
* `first_response_minutes`
* `resolution_time_hours`
* `agent_experience_years`
* `reopened`
* `channel`
* `customer_satisfaction`

## 📈 Key Business Questions

This project helps answer questions such as:

1. Which issue categories take the longest to resolve?
2. Which support channels have better service performance?
3. How does ticket priority affect resolution time?
4. What is the average first-response time?
5. How frequently are tickets reopened?
6. How does resolution performance relate to customer satisfaction?
7. Which areas of customer support may require improvement?
